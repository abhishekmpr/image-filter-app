# Image Filter App
## Description
A simple image filtering app that allows users to apply basic filters such as grayscale, invert, and blur to their uploaded images.

## Features
- Apply grayscale, invert, and blur filters to uploaded images
- Display original and filtered images side by side
- Allow users to upload their own images
- Provide a preview of the filtered image before applying the filter

## Technologies
- Frontend: React
- Backend: None
- Framework: Create React App
- CSS Framework: Bootstrap
- Image Library: React-Image-Processor

## How to Run
1. Clone the repository using `git clone https://github.com/your-username/image-filter-app.git`
2. Install dependencies with `npm install`
3. Start the app with `npm start`
